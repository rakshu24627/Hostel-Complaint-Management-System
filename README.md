# Hostel Complaint Management System

A simple beginner-level **C programming project** for managing hostel complaints.

## Features

- Add a new complaint
- View all complaints
- Search a complaint by ID
- Update complaint status
- Delete a complaint
- Save complaint data using file handling

## Technologies Used

- C Programming Language
- Structures
- Functions
- Arrays
- Loops
- Switch case
- File handling

## How to Run

### Using GCC

Open the terminal in the project folder and run:

```bash
gcc main.c -o hostel_complaint
```

Then run:

**Windows:**
```bash
hostel_complaint.exe
```

**Linux/macOS:**
```bash
./hostel_complaint
```

The program automatically creates `complaints.dat` when complaint data is saved.

## Project Objective

The objective of this project is to provide a simple way to record and manage hostel complaints such as electricity, water, cleaning, and room-related issues.
