# Project Report
## Hostel Complaint Management System

### 1. Title
Hostel Complaint Management System

### 2. Project Type
C Programming Project

### 3. Problem Statement
Managing hostel complaints manually can be difficult. Students may have problems related to rooms, electricity, water, cleaning, or other hostel facilities. A simple digital system can help record and manage these complaints.

### 4. Objective
The main objective is to create a simple C-based system that allows hostel complaints to be recorded, viewed, searched, updated, and deleted.

### 5. Methodology
The project is developed using the C programming language. A menu-based system is used so that the user can select different operations. Structures are used to store complaint details. Functions are used to keep the program organized. File handling is used to save complaint information so that it can be available when the program is opened again.

### 6. Main Features
1. Add complaint
2. View all complaints
3. Search complaint
4. Update complaint status
5. Delete complaint
6. Save complaint data

### 7. Concepts Used
- Variables
- Input and output
- If-else
- Switch case
- Loops
- Functions
- Arrays
- Structures
- File handling

### 8. Expected Outcome
The system provides a simple way to record and manage hostel complaints. It can help users keep complaint information organized.

### 9. Sustainable Development Goal
SDG 11 – Sustainable Cities and Communities.

### 10. Future Scope
The project can be improved by adding a login system, a graphical interface, administrator features, and a database.

### 11. Conclusion
The Hostel Complaint Management System demonstrates how basic C programming concepts can be combined to create a useful real-world application.
